# Creature Battler

## What is the Game?

Our game is a mix of Pokémon and Super Auto Pets. We took more inspiration from Super Auto Pets for having a buy stage where you purchase creatures and use them to fight though we took more inspiration from Pokémon for the combat, having creatures with multiple moves to select from to attack other creatures with.

## How to Access the Game

Our game is on it's own website hosted on an azure server [here](https://s2project.azurewebsites.net/)
